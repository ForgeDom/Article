**Налаштування першої автоматизації в n8n**

Для початку роботи з n8n потрібно виконати кілька кроків. Ось вони:

3. **Додати дії**: після вибору тригеру потрібно додати дії, які будуть виконуватися під час автоматизації. Наприклад, можна додати дія "Send Email", яка відправляє електронний лист з результатами автоматизації. Це важливо, оскільки дії визначають зміст автоматизації.

5. **Тестувати і запускати**: після налаштування всіх параметрів потрібно тестувати і запускати автоматизацію. Це важливо, оскільки тестування дозволяє перевірити працездатність автоматизації і виявити можливі помилки.

Наприклад, наступний код на Python демонструє автоматизацію відправки електронного листа:
```python
import smtplib
from email.mime.text import MIMEText

# Вказуємо параметри відправника і одержувача
from_addr = "example@gmail.com"
to_addr = "example@example.com"

# Вказуємо параметри листа
subject = "Тестовий лист"
body = "Це тестовий лист, відправлений автоматично"

# Створюємо текст листа
msg = MIMEText(body)
msg["Subject"] = subject
msg["From"] = from_addr
msg["To"] = to_addr

# Відправляємо лист
server = smtplib.SMTP("smtp.gmail.com", 587)
server.starttls()
server.login(from_addr, "пароль")
server.sendmail(from_addr, to_addr, msg.as_string())
server.quit()
```
Цей код можна використовувати як приклад дії "Send Email" в n8n.
